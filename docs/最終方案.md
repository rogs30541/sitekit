# SiteKit 最終方案（2026-09-25 定案）

## 1. 定位
WordPress 式開放套件：任何人在自己的主機獨自部署，每個客戶一套獨立系統；電商／課程／形象／品牌／專業服務五種用途，後台 AI 指令台＋MCP 雙路徑，台灣金流物流發票內建。

## 2. 部署平台（定案）
| 層級 | 平台 | 說明 |
|---|---|---|
| 預設推薦 | **Zeabur** | 功能 100%、硬碟持久、東京節點、儀表板零維運；專用伺服器約 US$4／月；Template 一鍵＋README 手動步驟 |
| 次要 | **Cloudflare Workers＋D1＋R2** | `apps/worker` 殼已完成並部署；免費方案 CPU 10ms 不足以跑密碼雜湊，實際建議付費方案；前台待 OpenNext |
| 可用 | VPS＋compose（Caddy）、Render（免費層已實測）、Railway、Fly、cPanel Node | 客戶已有主機時採用 |
| 不做 | Firebase、Vercel／Netlify 靜態、純 PHP 主機 | — |

## 3. 架構（已完成）
- 一核心（`packages/core`，零框架依賴）＋三殼（`apps/server` 單體＝預設、`apps/api` 分離、`apps/worker` Workers）＋三資料庫（PostgreSQL／SQLite／MySQL，由一份模型產生）。
- 交付化：`/setup` 六步精靈、自動機密、健康檢查、支援包、備份／還原／匯出、外掛（事件匯流排＋OPS 動作）、前台 i18n、發行管線（GHCR＋tarball＋GitHub Release）、六個 CI job。

## 5. 快速套版（本輪主體，v0.28.0）
- **來源**：三個指定成品站（工具箱儀表板／黑紅編輯宣言／大師課程平台）＋ Wix 全站範本分類與命名法 ＋ 五分類各 3 參考站；只取版面骨架（見 `docs/套版研究筆記.md`）。
- **資料模型**：`packages/shared/src/site-templates/`
  - `sections.ts`：區塊 schema（20 種 kind，每種含 variant）——首頁與「區塊頁」共用。
  - `theme.ts`：主題參數（mode／accent／font／radius／header／footer／container）→ settings `theme.*`。
  - `templates/<category>.ts`：五分類 × 10 ＝ 50 套，每套＝主題＋選單＋首頁區塊＋子頁區塊（關於／服務／聯絡／課程／商店…）。
- **套用**：core `SiteTemplateService.apply(id)`＝寫 settings（theme.*、home.sections）、選單（header／footer）、頁面（Content type=page，`design: { kind: 'sections', sections }`，slug 冪等），不動商品／課程／文章。
- **接口**：OPS `list_site_templates`／`apply_site_template`（mutating、confirm）；MCP 同名工具；後台「網站設定 → 套版庫」（分類頁籤、線框預覽、套用）；精靈「站名與網址」後新增「選擇版型」步驟（可跳過）。
- **前台**：`SectionRenderer`（取代 HomeSections）渲染全部 kind／variant；`/p/[slug]` 支援區塊頁；主題參數在 root layout 轉 CSS 變數（含深色模式、字型、圓角、頁首樣式）。
- **驗收**：e2e p31（50 套列表、套用一套後 settings／選單／頁面／首頁 HTML 皆對）；CI 全綠；Zeabur 正式站套一套示範。
