# 套版研究筆記（2026-09-25）

> 目的：為「快速套版」蒐集頁面架構與區塊組合。**只記錄版面結構（區塊類型、順序、欄數、色調）與命名法，不複製任何文字、圖片、程式碼或品牌素材。** 指定的三個成品站其中 ifreeaprogram.com 頁尾明示所有工具／內容／視覺為原創智財，本筆記與後續套版只取「版面骨架」的通用模式。

## 一、指定成品站（版型必用）

### 1. ifreeaprogram.com/dashboard（登島者學院工具箱）→ 版型「工具箱儀表板」
- 型態：**會員登入後的工具／課程入口頁**（非公開首頁）。深色底、單一亮色點綴（青綠）＋黃色副按鈕。
- 頂列：品牌名 · 副標 · 目前頁；右側帳號 email＋登出。
- 區塊順序：
  1. **問候 Hero**：小標籤（YOUR TOOLBOX）→ 大字「<名字>，歡迎回來」→ 一句說明。
  2. **分類分頁卡**：四張等寬卡（看全部／教學篇／實作篇／程式區）各帶英文小標與數量，點選過濾下方卡片。
  3. **工具卡片格**（2 欄）：每卡＝代號標籤（T01 · BUILD）＋標題＋段落說明＋滿寬 CTA 按鈕；分類不同顏色（教學／實作／程式）。
  4. **頁尾**：品牌＋版權＋授權聲明框＋技術註記。
- 取用要點：分類分頁卡＋代號卡片格＝「會員專區／課程工具箱／服務入口」通用骨架；深色＋單色點綴。

### 2. airuru.cc（噯嚕嚕短影音行銷）→ 版型「黑紅編輯宣言」
- 型態：**B2B 服務形象站**，黑底、白字、紅色強調；標題字級極大（宣言式）；右下 LINE 浮動鈕；頂部有閱讀進度條。
- 頂列：品牌名（紅色關鍵字）＋ 5 個選單＋紅色 CTA「免費諮詢」。
- 首頁區塊順序：
  1. **宣言 Cover**（滿版、min-height 100vh）：三行超大標題，一行紅色關鍵字。
  2. **論點 Thesis**：左文右圖（折線圖），下方 3 個大數字統計＋累積成績（2 億＋／1 億＋）。
  3. **服務 Services**：左側黏性直式影片（手機比例）＋右側服務清單（圖示＋標題＋一句說明＋箭頭）。
  4. **實戰案例 Cases**：客戶名＋產業一句＋三個大數字（粉絲／變現／啟動）。
  5. **實績戰報 Portfolio**：36 張縮圖牆。
  6. **見證 Testimonials**：4 張卡（頭像＋引言）。
  7. **聯絡 Contact**：一句收尾標題＋三種聯絡方式卡。
- 子頁：/courses（課程銷售頁：Hero 三特色小卡→痛點 4 卡→技能 6 卡→見證 8→方案／價值 11 卡→完整內容＋贈品）；/about（標題→創辦人左圖右文→使命 3 卡→團隊 3 卡→CTA）。
- 取用要點：大字宣言＋數字證明＋黏性影片服務清單＋案例數字＋見證＋聯絡＝行銷／代操／顧問服務站骨架。

### 3. shifu.tw（師父大師課程平台）→ 版型「大師課程平台」
- 型態：**多講師課程市集**，黑底，粉紅／紅點綴，Bootstrap 式卡片格。
- 頂列：找課程／找師父／看文章／常見問題／我的課程；搜尋、購物車、會員圖示。
- 首頁區塊順序：
  1. **Hero 輪播**（講師肖像＋課名＋CTA，點點指示）。
  2. **募資課程**：橫向卡片（封面＋倒數標籤＋進度條＋人數／達標％）。
  3. **實戰陪跑課**：卡片列。
  4. **熱門排行**：No.1〜N 直式肖像卡。
  5. **課程分類**：圖示磚牆。
  6. **限時優惠**：卡片列。
  7. **立即上課**：卡片列。
  8. **推薦專欄**：文章列。
  9. **影片區**：輪播。
- 列表頁 /course/findcourse：左側分類側欄（全部／募資／熱門／限時／陪跑＋主題分類）＋右上搜尋＋卡片格（封面、標題、講師、價格／原價、時長、人數）。講師頁：左側分類＋講師列（頭像＋名＋簡介＋箭頭）。
- 取用要點：市集首頁＝輪播＋多條「主題卡片列」＋排行＋分類磚＋專欄；列表頁＝側欄過濾＋卡片格。

## 二、Wix 範本庫（zh.wix.com/website/templates）
- 分類：單頁面（敬請期待／登陸頁面）、eCommerce（時尚／珠寶／藝術工藝／家居／美容／食物／運動／電子／兒童／書籍／寵物）、作品集及簡歷、部落格、商業（諮詢教練／行銷廣告／技術應用／財務／法律／房地產）、工業、健康與保健（健康／運動體適能）、活動、教育（學校大學／在線教育／課程學程）、社群、時尚風格、美容美髮、設計（建築／室內／藝術插畫／圖畫網絡／建立品牌／時尚設計）、攝影、音樂、創意藝術、影片、餐廳食物、旅遊觀光。全部 107 頁 × 12。
- **命名法**：「產業／用途 (風格)」，風格詞：現代、經典、簡易、簡約、專業、正式、深色、暗黑、粗體、柔和、暖色調、自然、活力、動態、插畫風、編輯風、幾何、單色、漸層、抽象、俐落、精緻、典雅、奢華、都會、復古、有趣、清新、冷靜。→ 本套件套版命名採「分類・用途 (風格)」。
- 商業類 96 個範本中的骨架高頻：Hero（左文右圖或滿版）→ 服務 3〜4 卡 → 關於／數字 → 案例／作品 → 見證 → FAQ／流程 → CTA／聯絡。登陸頁類：單頁、長捲動、多 CTA、方案表。
- eCommerce 類骨架：Hero 主打商品／季節 → 分類磚 → 新品／熱銷格 → 品牌故事（左圖右文）→ 見證／UGC → 電子報 → 頁尾多欄。
- 教育類骨架：Hero → 課程格 → 特色（為何選我們）→ 講師 → 學員見證 → 方案／報名 → FAQ → CTA。
- 設計／品牌類骨架：滿版大圖或大字 → 作品格（瀑布／等格）→ 關於一段 → 服務 → 聯絡；留白多、字級大。

## 一頁式網頁（銷售頁）骨架：airuru.com.tw（2026-09-25 實看，只取結構）

- 頁面形態：手機優先單欄（max-width 約 720px）、上半段為連續長圖（12 張），下半段為程式區塊；常駐底部 CTA（類別標籤＋「選擇場次報名 →」＋主按鈕）、右側浮動 LINE／會員／購物車。
- 敘事序列：①hero 主張（大標＝獨特主張、副標＝承諾）②信任帶（「別人只能…，我們直接…」）＋保證徽章（不滿意退費）③痛點卡 ×5（圖示＋標題＋兩句）④權威／人物（大數字＋簡介＋金句）⑤承諾（三個結果）⑥公式視覺（變數 × 變數 × 變數 ＝ 結果）⑦模組卡 ×N（模組標題＋「解決：」＋3–4 張卡＋收束句）⑧優惠（一位／兩位／現省）⑨見證（影片橫向捲動）⑩場次卡（圖、標題、時間、地點、名額、單價、數量、CTA）⑪頁尾（公司／統編／地址／隱私）。
- 對應本套件：`packages/shared/src/sales-templates/`（DesignDoc 內文＋SalesPageDoc theme／sections／notice）；課程類「霓虹爆款」＝此骨架；其他四類（電商／形象／品牌／專業服務）依同一敘事反推；每類 5 種風格配色。文案／圖片一律佔位，不含原站任何素材。
