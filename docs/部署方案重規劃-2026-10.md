# 部署方案重規劃（2026-10-22：Zeabur 停止服務）

## 0. 背景與現況

- 2026-10-22 使用者告知 Zeabur 故障且將停止服務。正式站 `https://aigc-sitekit.zeabur.app` 當下仍可連（v0.38.0，健康檢查 ok），但平台不可再依賴。
- 正式站內容幾乎是空站：品牌名「AIGC創客學堂」、一位超級管理員、設定值；沒有商品／課程／文章／上傳檔（公開 API 與首頁皆無媒體網址）。**資料搶救成本很低**：一份「匯出（含機密）」JSON 就夠。
- 原本「Zeabur 預設推薦」寫進了 README、安裝精靈文案、`docs/最終方案.md` §2、`deploy/zeabur-template.yaml`。這些要一起改。

匯出／匯入是既有功能：`ExportService.exportAll` ↔ `sitekit import FILE --confirm`（或後台「匯入」）。上傳檔不在 JSON 內，要另外複製。

## 3. 建議

**主線改為 A（VPS ＋ compose）**，理由：唯一與 Zeabur 功能完全對等的路；最便宜；不綁任何平台（這次的教訓）；compose 已有 CI 煙霧測試每版把關。
**次要維持 B（Cloudflare）**：殼已上線，當零維運／高流量備援，但要 Paid。
**過渡用 C（Render）**：如果今天就要一個能開的正式網址而 VPS 還沒買，先用 `render.yaml` 部署 starter；之後再搬到 A（同一份匯出檔匯入即可）。

網域：`*.zeabur.app` 會跟平台一起消失，**一定要有自有網域**（A／C 都需要；B 可先用 `*.workers.dev`）。

## 4. 搬遷步驟（方案 A）

1. 買 VPS（Ubuntu 24.04，開 22／80／443），網域 A 記錄指到 VPS IP。
2. 主機上：`apt install docker.io docker-compose-plugin`、`git clone https://github.com/rogs30541/sitekit`（只需要 `deploy/compose/`）。
3. `cd deploy/compose && cp .env.example .env`，填 `DOMAIN`、`POSTGRES_PASSWORD`；`SITEKIT_IMAGE=ghcr.io/rogs30541/sitekit:0.38.0`（或 latest）。
4. `docker compose up -d` → 開 `https://<DOMAIN>/api/health` 應回 ok；首次會導到 `/setup`。
5. 匯入舊站：`docker compose exec sitekit node apps/server/bin/sitekit.mjs import /data/export.json --confirm`（先把匯出檔放進 `sitekit-data` volume，或用後台「匯入」上傳）。匯入含機密＝管理員帳密、OPS token 一併還原。
6. 後台「網站設定」把 `site.url` 改成新網域；金流回呼網址（藍新等）到各商店後台更新。
7. 關掉 Zeabur 服務（或等它停）。

搬遷到 C（Render）：Dashboard → New → Blueprint → `render.yaml` → 填 `FRONTEND_URL` → Deploy → 後台匯入同一份檔。
