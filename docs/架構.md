# SiteKit 架構說明（v0.3，P2 變現）

## 服務拓撲

```
瀏覽器 ── 同網域 ──> web (Next.js)  ── rewrites /api/* ──> api (NestJS) ──> PostgreSQL（Prisma）
                     │ middleware：301 導向表（每 60 秒從 api 取）                 └─ Redis（P3 佇列，尚未接）
                     │
訂閱制 AI 工具 ── MCP stdio ──> mcp/server.mjs ── Bearer OPS_TOKEN ──> /api/ops/*
```

- `web` 與 `api` 各自部署（Zeabur 兩服務加 postgres、redis 共四個），同網域靠 Next.js rewrites 把 `/api/*` 轉到 api，cookie 同源、不碰 CORS。
- 所有金錢與授權寫入（orders、entitlements、credit_ledger）只有 api 能寫，前端永不直寫資料庫。
- Session 由 api 發 httpOnly cookie（`sk_session`＝隨機 id），狀態與角色以 `sessions` 表為準，登出即失效。web 只轉發 cookie。

## 後台雙路徑

| | MCP 路徑 | AI API 路徑 |
|---|---|---|
| 控制器 | `apps/api/src/modules/ops/ops.controller.ts` | `apps/api/src/modules/admin-ai/admin-ai.controller.ts` |
| 守衛 | `OperatorTokenGuard`（Bearer = `OPS_TOKEN`；未設 token 即整條路徑關閉） | `AdminSessionGuard`（DB session，role 必須是 admin/superadmin；帶 Bearer 直接拒絕） |
| 可做的事 | `OPS_ACTIONS` 全集 | 同一份 `OPS_ACTIONS`，由後台 UI 的 AI 助手代為觸發 |
| 執行層 | `OpsService.run(action, params, actor)` | 同左 |
| 稽核 | `audit_logs.actor = "mcp"` | `audit_logs.actor = "admin-ai:<userId>"` |

規則：**新增任何後台維運功能，先在 `packages/shared` 的 `OPS_ACTIONS` 登記，再在 `OpsService` 實作，兩條路徑自動同時獲得。** 不得為 MCP 或 AI 另寫一套邏輯。

目前動作：`status`、`deploy`（P1 只記稽核，尚未接部署平台）、`migrate`（同上）、`get_settings`（isSecret 遮蔽）、`update_settings`（key 含 secret/key/token/password 自動標記機密）、`import_content`（搬運器）、`audit`。

| `health` | 健康檢查 |

## 開發模式鐵律

- `apps/api` 開發與建置一律走 `nest start --watch` / `nest build`（tsc）。**不可用 tsx／esbuild 直跑**：esbuild 不產生 `emitDecoratorMetadata`，Nest 建構子注入會拿到 undefined，任何有相依的 controller 都回 500（骨架期實測踩到）。
- api 啟動時若 cwd 有 `.env` 會用 `process.loadEnvFile` 載入（不覆蓋既有變數）；正式環境由平台注入，`DATABASE_URL` 必填、缺了直接不啟動。
- 本機免 Docker 資料庫：`npm run dev:db` 直接驅動 `@embedded-postgres` 的 initdb／pg_ctl／postgres。**Windows 陷阱**：專案路徑含中文（cp950）時 initdb 會炸 `invalid byte sequence for encoding UTF8`，所以二進位與資料目錄一律放 ASCII 路徑（`%LOCALAPPDATA%/sitekit`），且 `fs.cpSync` 複製大量 exe/dll 會無聲退出，改用 robocopy／cp。
- 測試時若用 git-bash 的 curl 送中文 JSON，payload 會以 cp950 送出而變亂碼；驗中文請走瀏覽器或 PowerShell `-Encoding utf8`。

## 金流鐵律（從度哥繼承）

1. 授權欄位永不開放前端寫入：`entitlements`、`orders` 只在 api 的 `OrdersService.markPaid` 內寫。
2. 付款以伺服器回呼為準：`/api/payments/newebpay/notify` 驗 TradeSha、解密、驗 CheckCode、比對金額，通過才 `markPaid`；`ReturnURL` 導回只重複同一段處理再轉到 `/order-result`，頁面本身只輪詢狀態。
3. 回呼冪等：同 orderId＋type＋tradeNo 的 `payment_events` 不重複寫；`markPaid` 對已 paid 直接回傳。
4. 媒體網址即時簽發、帶時效：Bunny token 1 小時，`/api/learn/play/:chapterId` 先驗授權（或試看）。
5. 本機用 `payment.provider=mock`（非 production 才允許），假閘道回呼以 HMAC(SESSION_SECRET) 簽章，任意呼叫會被拒。

新增遷移的方法（`migrate dev` 在非互動環境不可用）：`prisma migrate diff --from-url $DATABASE_URL --to-schema-datamodel prisma/schema.prisma --script > prisma/migrations/<ts>_<name>/migration.sql`，再 `migrate deploy`。
